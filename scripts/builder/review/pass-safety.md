Security and robustness. Follow untrusted input from every write path to storage and from storage to every place it is rendered: is it sanitized on each path, with an allow-list, including indirect writers (translation, copy, import, templates)? What happens with wrong types, null, empty or whitespace-only values, malformed input, very long input: does the server answer 400 or crash with a 500, does a client crash or render nothing? Look for crash paths in client rendering code and for anything that runs per item in a list and could be slow.
